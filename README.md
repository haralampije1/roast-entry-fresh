## Entry

This program writes a single roast of my own AI agent to `/output/entry.txt` as required by the competition.

The roast (75 characters, well under the 200 limit):
```
My agent needed a fresh pair of eyes, so it spawned itself wearing glasses.
```

## Building

```bash
npx tsx main.ts
```

Outputs to `/output/entry.txt`.
